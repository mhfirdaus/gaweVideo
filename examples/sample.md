# Belajar Python untuk Pemula

## Apa itu Python?

Python adalah bahasa pemrograman yang mudah dipelajari dan sangat powerful.
Digunakan untuk web development, data science, AI, dan banyak lagi.

## Hello World

Mari kita mulai dengan program pertama:

```python
print("Hello, World!")
print("Selamat belajar Python!")
```

## Variabel dan Tipe Data

Python memiliki beberapa tipe data dasar:

- **String**: Teks, contoh `"Hello"`
- **Integer**: Bilangan bulat, contoh `42`
- **Float**: Bilangan desimal, contoh `3.14`
- **Boolean**: True atau False

```python
nama = "Budi"
umur = 25
tinggi = 175.5
is_programmer = True

print(f"Nama: {nama}")
print(f"Umur: {umur} tahun")
```

## Kesimpulan

Python adalah pilihan tepat untuk memulai belajar programming!
